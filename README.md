# 📌 Problem Statement

**PS ID:** SIH2026

**Theme:** Smart Agriculture & Precision Farming

**Organization:**Ministry of Agriculture & Rural Development

### Problem Description
Farmers often face crop losses due to late disease detection, pest infestations, and improper fertilizer management. Traditional monitoring methods are time-consuming and require expert knowledge.

---

# 💡 Proposed Solution
Pest disease monitoring system is an intelligent agriculture platform that combines:

✅ AI-based disease detection

✅ Pest infestation identification

✅ Soil NPK monitoring

✅ Fertilizer recommendation

✅ Weather-based advisory

✅ Real-time alerts

✅ Farmer dashboard

The platform helps farmers make data-driven decisions and improve crop yield.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/Yogesh98732/crop health system.git
cd NutriTrack
```

## Backend Setup

```bash
cd backend
npm install
npm run dev
```

## Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

## AI Service Setup

```bash
cd ai-service

python -m venv .venv

.venv\Scripts\activate

pip install -r requirements.txt

python app.py
```
